使用 CC Switch 配置多个 AI 应用

CC Switch（CCS） 支持管理多个 AI 应用的接入配置。你可以先选择需要的应用，再导入极速 AI 的 API 密钥，并在图形界面中完成对应配置。

应用列表包括 Claude Code、Claude Desktop、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes、Pi、MiniMax Code 等，具体以你安装的 CC Switch 版本为准。

操作顺序：安装 CC Switch → 选择并显示需要的应用 → 完成对应应用设置 → 创建 API 密钥 → 导入到 CCS → 检查供应商与模型配置 → 保存并在应用中验证。

下面先介绍通用操作，再以 Codex 演示推荐设置、获取模型列表和重启流程。使用其他应用时，按对应应用的接入说明完成配置。

1. 安装 CC Switch

打开 CC Switch 官网，按照官网说明下载并安装适合你操作系统的版本。

安装完成后打开 CC Switch，先选择你准备配置的应用。

2. 选择并显示需要的应用

  1. 点击 CC Switch 左下角的 应用，打开应用列表。
  2. 找到准备使用的应用，例如 Claude Code、Claude Desktop、Codex 或 OpenClaw。
  3. 打开该应用右侧的 显示 开关，让它出现在左侧导航栏中。可以同时显示多个应用。
  4. 在左侧导航栏选择需要配置的应用，进入它的配置页面。

「显示」开关控制导航栏入口。显示应用不代表已经完成安装或 API 配置；如果列表提示「未安装」，请先按该应用的安装说明完成安装。

3. 设置推荐选项（仅 Codex 用户）

使用其他应用可跳过这一步，继续创建 API 密钥。如果你准备配置 Codex，在创建和导入密钥之前，先进入 设置 → 应用配置 → Codex，建议打开下面两个选项。

  1. 点击 CC Switch 左下角的 设置。
  2. 在设置页左侧点击 应用配置，向下找到 Codex 设置区域。
  3. 建议打开 非接管切换时保留官方登录。
  4. 建议打开 统一 Codex 会话历史。

以上两项为建议开启的选项。完成设置后，返回主界面，继续创建和导入 API 密钥。

4. 创建 API 密钥

  1. 登录 极速 AI 控制台 → API 密钥。
  2. 点击 创建密钥，填写便于识别的名称，并根据准备使用的应用、模型与接口要求选择对应分组。
  3. 保存密钥，回到 API 密钥列表，找到刚刚创建的那一行。

5. 点击「导入到 CCS」

在 API 密钥列表中，点击目标密钥右侧操作栏中的 导入到 CCS。如果浏览器询问是否打开 CC Switch，允许打开，并在 CC Switch 中完成导入。

导入后，确认供应商出现在准备配置的应用页面中，再继续检查配置。不同应用使用的接口与字段可能不同，请按对应应用的接入说明核对。

6. 检查并编辑供应商

在 CC Switch 左侧选择 准备配置的应用，检查刚导入的极速 AI 供应商。需要修改时，进入该供应商的编辑页面。

以 Codex 为例：在左侧选择 Codex，找到刚导入的极速 AI 供应商，点击右侧的 铅笔图标，进入编辑页面。

7. 配置模型（以 Codex 为例）

下面展示 Codex 的模型配置方式。其他应用的模型字段和配置方式可能不同，请按对应应用的接入说明操作。

  1. 在编辑页面确认 API 请求地址 为 https://jisuai.net。
  2. 找到 模型列表 区域，点击 获取模型列表。
  3. 等待列表加载完成，将获取到的模型 全部勾选，添加到当前供应商的模型列表中。
  4. 点击右下角的 保存，保存本次配置。

8. 在对应应用中验证配置

完成对应应用的供应商与模型配置后，保存配置，并在应用中选择需要的模型，发送一条简短消息，确认能够正常响应。

Codex 用户：确认 CC Switch 中极速 AI 供应商处于 使用中 状态，然后退出并重新启动 Codex，让新的配置和模型列表生效。

如果 CC Switch 顶部提示 Codex 还在用旧的模型列表，点击提示中的 重启 Codex 守护进程，再重新打开 Codex。此提示和操作仅适用于 Codex。

其他应用用户：按照对应应用的说明启用配置；如提示需要重启，请重新打开该应用后再验证。

遇到问题时

  • 左侧只有 Codex，找不到其他应用：点击左下角「应用」，打开目标应用右侧的「显示」开关，再从左侧进入该应用。
  • 点击导入没有打开 CC Switch：确认已安装并打开过 CC Switch，再返回浏览器重新点击「导入到 CCS」，并允许浏览器打开应用。
  • 应用的配置页面与示例不同：本文的编辑和模型截图以 Codex 为例。请先确认当前选择的应用，再按它的接入说明填写对应字段。
  • Codex 没有获取到模型：检查 API 请求地址、导入的密钥是否正确，以及密钥是否属于准备使用的分组，再重试「获取模型列表」。
  • Codex 保存后仍看不到新模型：确认已全部勾选并保存，随后重启 Codex；出现旧模型列表提示时，按提示重启 Codex 守护进程。

需要自行调用接口时，可查看 通用 API 接入教程。调用问题请参考 错误处理与排障。
