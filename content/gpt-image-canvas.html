通过极速画布生成图片

在极速 AI 控制台打开 极速画布，配置渠道和 API Key 后，就可以在 生图工作台 中输入提示词、选择模型并生成图片。

操作顺序：极速画布 → 配置 → 添加渠道 → 编辑并填入 API Key → 选择模型 → 拉取模型列表 → 全选当前列表 → 确定 → 保存 → 生图工作台。

生图必须使用生图分组的密钥。文本与生图渠道的配置方法相同，但需要分别填写对应的接口地址和 API Key。本文会先说明渠道配置方法，再演示生图渠道和工作台。

1. 从控制台打开极速画布

登录 极速 AI 控制台，在左侧菜单的 工具 区域点击 极速画布。

2. 打开配置，添加渠道

进入极速画布后，点击左侧的 配置，在「配置与用户偏好」页面选择 渠道。

按用途点击 ＋ 极速AI-文本 或 ＋ 极速AI-生图 添加对应渠道，然后点击渠道右侧的 编辑。准备生成图片时，选择「极速AI-生图」。

渠道协议接口地址API Key
极速AI-文本OpenAIhttps://jisuai.net对应文本分组的密钥
极速AI-生图OpenAIhttps://api.jisuai.net生图分组的密钥

两个渠道分别配置。生图渠道使用 https://api.jisuai.net，请核对正在编辑的渠道名称和接口地址。

3. 编辑渠道，填写 API Key

  1. 在 控制台 → API 密钥 中创建对应分组的密钥。生图分组的选择示例见下文第 6 步。
  2. 返回画布的渠道编辑页，核对 渠道名称、协议、接口地址。
  3. 在 API Key 输入框中填入刚创建的密钥。
  4. 点击 选择模型，进入模型选择窗口。

4. 拉取模型，全选并确定

  1. 在「选择渠道模型」窗口点击右上角的 拉取模型列表。
  2. 等待模型列表加载完成，点击 全选当前列表。
  3. 确认需要的模型已勾选，点击右下角的 确定。

5. 返回编辑页，保存渠道

点击「确定」后，返回渠道编辑页面。确认模型已经出现在 渠道模型 列表中，再点击右上角的 保存。

6. 生图渠道：使用生图分组密钥

生成图片前，请在控制台为生图单独创建一枚 API Key，并选择 生图分组。截图中的分组示例为 ChatGPT-生图-渠道一 和 ChatGPT-生图-渠道二，具体可用分组以控制台当前显示为准。

  1. 回到极速画布的 配置 → 渠道，添加或编辑 极速AI-生图。
  2. 确认协议为 OpenAI，接口地址为 https://api.jisuai.net。
  3. 在 API Key 中填入刚创建的 生图分组密钥。
  4. 按相同方法点击 选择模型 → 拉取模型列表 → 全选当前列表 → 确定。
  5. 回到编辑页，确认生图模型已添加、能力选为 生图，然后点击右上角 保存。

7. 打开生图工作台，开始生成

  1. 点击画布左侧的 生图工作台。
  2. 在 提示词 中描述想生成的画面；需要参考图时，可上传图片或使用剪贴板入口。
  3. 在 模型 中选择刚配置的生图模型。
  4. 根据需要设置质量、尺寸、分辨率、宽高比和生成张数。
  5. 点击底部 开始生成，等待右侧显示生成结果。
  6. 生成完成后，可以点击 下载，或选择 加入我的资产、加入参考图。

配置检查与排障

  • 工作台找不到生图模型：检查生图渠道是否已拉取模型、全选并确定，以及是否点击了渠道编辑页的「保存」。
  • 密钥或模型不匹配：检查密钥是否属于生图分组，生图渠道接口地址是否为 https://api.jisuai.net。
  • 模型能力不正确：回到生图渠道编辑页，确认目标模型的能力选择为「生图」，保存后再返回工作台。

需要通过代码调用图片接口，可查看 GPT-Image 使用指南；其他调用问题请参考 错误处理与排障。
