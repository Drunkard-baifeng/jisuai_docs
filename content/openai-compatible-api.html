适用场景

如果你的应用支持自定义 OpenAI Provider、Base URL 和 API Key，就可以接入 jisuai.net。本教程适用于自建 Agent Harness、后端服务、自动化脚本，以及支持 OpenAI 兼容接口的第三方应用。

接入参数

配置项填写值
Provider / API 类型OpenAI Compatible
Base URLhttps://jisuai.net/v1
API Key在 jisuai.net 控制台创建的 OpenAI 分组密钥
模型填写控制台当前可用的实际模型 ID，例如 gpt-5.6-sol

如果应用要求填写完整接口地址，请使用：

  • Chat Completions：https://jisuai.net/v1/chat/completions
  • Responses：https://jisuai.net/v1/responses
不要重复拼接路径：SDK 的 base_url 已经填写到 /v1 时，不要再填成 /v1/chat/completions，SDK 会自动追加具体接口路径。

选择哪种接口

接口请求字段适合场景
Chat Completionsmessages兼容现有聊天客户端、旧版 SDK 和已有 OpenAI 接入代码
Responsesinput新建 Agent Harness、工具调用工作流和面向后续 OpenAI 能力演进的应用

已有应用优先保持原接口，减少迁移成本；新建 Agent Harness 如果框架支持，建议优先使用 Responses API。不要把 Chat Completions 的 messages 原样传给 Responses 的 input。

Chat Completions：curl

export JISUAI_API_KEY="YOUR_JISUAI_API_KEY"

curl https://jisuai.net/v1/chat/completions \
  -H "Authorization: Bearer $JISUAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-sol",
    "messages": [
      {"role": "system", "content": "你是一个简洁的编程助手。"},
      {"role": "user", "content": "用 Python 写一个二分查找函数。"}
    ]
  }'

Chat Completions：Python SDK

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["JISUAI_API_KEY"],
    base_url="https://jisuai.net/v1",
)

completion = client.chat.completions.create(
    model="gpt-5.6-sol",
    messages=[
        {"role": "system", "content": "你是一个简洁的编程助手。"},
        {"role": "user", "content": "解释什么是 Agent Harness。"},
    ],
)

print(completion.choices[0].message.content)

Responses：curl

export JISUAI_API_KEY="YOUR_JISUAI_API_KEY"

curl https://jisuai.net/v1/responses \
  -H "Authorization: Bearer $JISUAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-sol",
    "input": "列出构建 Agent Harness 时最重要的三个模块。"
  }'

Responses：Python SDK

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["JISUAI_API_KEY"],
    base_url="https://jisuai.net/v1",
)

response = client.responses.create(
    model="gpt-5.6-sol",
    input="给出一个最小可用 Agent Harness 的目录结构。",
)

print(response.output_text)

自建 Agent Harness 的配置建议

JISUAI_API_KEY=YOUR_JISUAI_API_KEY
OPENAI_BASE_URL=https://jisuai.net/v1
OPENAI_MODEL=gpt-5.6-sol
OPENAI_API_MODE=responses
  • 服务端从环境变量读取 API Key，不要把密钥写入源码或前端包。
  • 把 base_url、模型和接口模式做成独立配置，避免在业务代码中散落硬编码。
  • 设置合理的连接超时、总超时和有限次数重试；不要对 401、403 等鉴权错误盲目重试。
  • 记录请求 ID、模型、耗时和状态码，不要在日志中记录完整 API Key。
  • 需要流式输出时，在请求中加入 stream: true，并确认你的 SDK 或客户端支持对应接口的流事件格式。

第三方应用怎么填

  1. Provider 选择 OpenAI、OpenAI Compatible 或自定义 OpenAI。
  2. Base URL 填 https://jisuai.net/v1。
  3. API Key 填 jisuai.net 控制台创建的密钥。
  4. 接口模式可选时，按应用支持情况选择 Chat Completions 或 Responses。
  5. 填写实际模型 ID，保存后发送一条最小测试请求。

如果应用会自动在地址末尾拼接 /v1，则按它的字段说明填写 https://jisuai.net；判断标准是最终请求必须落到上面列出的完整接口地址，不能出现重复的 /v1/v1。

最小验证与排障

  1. 先用本文的 curl 示例验证密钥、模型和接口是否可用。
  2. curl 成功后再配置 SDK 或第三方应用，避免同时排查多个变量。
  3. 401：检查 Authorization 是否为 Bearer API_KEY，以及密钥是否完整有效。
  4. 404：检查域名、/v1 和接口路径，确认使用 https://jisuai.net。
  5. 400：检查所选 API 对应的请求结构，以及模型 ID 是否正确。
  6. 429：检查余额、额度和速率限制，并采用指数退避重试。
