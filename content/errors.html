推荐排障顺序

遇到问题时，按照以下顺序排查可以最快定位原因：

01

检查网络

确认能正常访问 jisuai.net。在终端运行 curl https://jisuai.net 测试连通性。

02

检查配置

确认 Base URL 和 API Key 设置正确。注意 Codex 需要加 /v1 后缀。

03

检查账户

确认账户余额充足，API Key 处于启用状态，所选模型在当前套餐中可用。

常见错误

错误信息 可能原因 解决方式
401 Unauthorized API Key 无效或过期 在控制台检查密钥状态，重新生成密钥
429 Too Many Requests 请求频率超限 稍等片刻后重试，或联系客服提升限额
Connection refused Base URL 配置错误 检查环境变量中的 URL 是否正确
Model not found 模型名称错误 检查模型名拼写，参考控制台中的可用模型列表
Insufficient balance 账户余额不足 在控制台充值后重试

什么时候联系支持

如果以上排查步骤都无法解决问题，或者出现以下情况，建议通过控制台提交工单：

  • 同一份配置在多台机器上都稳定失败。
  • 费用记录与实际调用明显不符。
  • 返回内容异常（如乱码、截断、与模型能力不符）。

如需进一步协助，请通过 jisuai.net 控制台联系支持团队。
