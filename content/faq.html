jisuai.net 和官方 API 有什么区别？

jisuai.net 是 AI 模型的中转接入服务。你通过 jisuai.net 的域名和密钥访问 Claude、GPT、DeepSeek 等模型，jisuai.net 负责请求转发、计费和日志记录。模型本身的能力与官方完全一致。

支持哪些工具？

目前支持以下编码工具的接入：

  • Claude Code（Anthropic 官方 CLI）
  • Codex CLI（OpenAI 编码工具）
  • OpenClaw（开源 Agent 工具）
  • Hermes Agent（Nous Research 开源 Agent）
  • DeepSeek Harness（DeepSeek AI 开源 Agent Harness）
  • Cherry Studio（桌面端 AI 助手）
  • Claude Desktop（通过第三方 Provider 配置）
  • VS Code 插件（Cline、Continue 等）
  • JetBrains 插件

计费方式是怎样的？

jisuai.net 采用 按量计费 的方式，与官方的 token 计价保持一致。每次 API 调用都会记录输入 token 和输出 token 的用量，乘以对应的倍率得到实际费用。你可以在控制台查看每一笔调用的详细费用明细。

需要翻墙吗？

本站仅面向境外用户提供服务。请在使用前确认符合您所在国家或地区的法律法规，并依法合规使用 AI 服务。

如何注册和充值？

  1. 访问 jisuai.net 注册账号并完成邮箱验证。
  2. 在控制台创建 API Key。
  3. 通过控制台的充值入口进行充值（支持支付宝/微信）。
  4. 参考 自动配置工具（CC Switch） 配置应用，或查看 通用 API 接入教程。

遇到问题怎么办？

先查看 错误处理与排障 文档，按照推荐的排查顺序逐步检查。如果问题仍然无法解决，可以通过控制台提交工单或联系客服。
