整体流程

01

注册账号

访问 jisuai.net 注册账号，完成邮箱验证。

02

创建密钥

在控制台生成 API Key，用于工具的身份认证。

03

配置工具

在 Claude Code、Codex 或 IDE 中配置 Base URL 和 API Key。

核心概念

Base URL

jisuai.net 的接入域名，替代官方 API 地址。所有工具统一使用同一个域名。

API Key

你在 jisuai.net 控制台创建的密钥，格式为 sk-jisuai-***。

倍率

不同模型分组有不同的费用倍率，倍率越低价格越便宜。详见定价页。

接通后检查

  • 工具能正常连接并返回结果。
  • 控制台中能看到对应的调用记录。
  • 费用明细与预期一致。
