jisuai.net 是什么

jisuai.net 不是聊天界面，而是一层面向开发团队的 AI 编码接入层，用来统一模型、工具与计费视角。

  • 一个账号，同时使用 Claude Code 和 Codex
  • 统一的 API 接入与网络环境
  • 与官方一致的精确计费
  • 每一笔调用，费用可查

为什么选择 jisuai.net

当团队同时使用多种 AI 编码工具时，最常见的问题不是模型本身，而是接入方式不统一。

  • 配置分散 → 统一域名与密钥格式
  • 费用核对困难 → 精确的调用日志与明细
  • 网络不稳定 → 持续优化的链路策略
  • 工具切换成本高 → 5 分钟完成配置

支持的工具与模型

Claude Code

Anthropic 官方 CLI 工具，支持 Opus 4.7、Sonnet 4.6、Haiku 4.5。

Codex CLI

OpenAI 编码工具，支持 o3、GPT-5.6-Sol 等模型。

DeepSeek

通过兼容 API 与服务端模型映射接入，具体模型和分组以控制台为准。

推荐阅读顺序

  1. 先看 常见问题 和 平台使用指南，了解平台与密钥的使用方式。
  2. 使用 自动配置工具（CC Switch） 配置应用；需要调用接口时，查看 通用 API 接入教程 或 GPT-Image 使用指南。
  3. 想通过图形界面生成图片，可查看 GPT 生图 · 画布使用，完成渠道配置后进入生图工作台。
  4. 遇到问题时，查看 错误处理与排障。
