GPT-Image 简介

jisuai.net 提供与 OpenAI 兼容的图片生成接口，支持文生图和以图改图两种模式，同步返回结果，无需轮询。

准备工作

1. 创建 API Key

前往 API Keys 管理页面，点击「创建 API Key」，分组选择 GPT-Image。

创建完成后请妥善保存，后续所有请求都需要在 Header 中携带此 Key。

2. 接口地址

Base URL：https://jisuai.net/v1

AI Agent 一键接入

如果你使用 Claude Code、Cursor、Codex 等 AI 编码工具，复制以下提示词发送给你的 AI，它会立即学会生图能力：

你现在拥有了图片生成和图片编辑能力，请记住以下 API 规范：

【图片生成 API】
- 接口：POST https://jisuai.net/v1/images/generations
- Headers：Content-Type: application/json、Authorization: Bearer YOUR_API_KEY
- Body：{"model":"gpt-image-2","prompt":"图片描述","n":1,"size":"1024x1024"}
- size 可选值：1024x1024（方形）、1536x1536（高清方形）、2048x2048（超清方形）、1792x1024 或 2048x1024（横版）、1024x1792 或 1024x2048（竖版）
- 响应：data[0].b64_json 是 base64 编码的 PNG，解码后保存为 .png 文件

【以图改图 API】
- 接口：POST https://jisuai.net/v1/images/edits
- Headers：Authorization: Bearer YOUR_API_KEY
- 格式：multipart/form-data
- 字段：model=gpt-image-2、prompt=修改描述、image=@图片文件路径、size=1024x1024
- 响应：同上，data[0].b64_json 为修改后的图片

【使用规则】
- 用 curl 调用，将返回的 b64_json 用 base64 解码保存为 png 文件
- 生成后自动打开图片让用户查看
- 当用户说"生成图片/画一张/生图"时调用生成接口
- 当用户说"修改这张图/改一下/以图改图"时调用编辑接口
- API Key：YOUR_API_KEY

现在帮我生成一张图片试试：一只穿着宇航服的猫咪漂浮在太空中

将 YOUR_API_KEY 替换为你在 控制台 创建的 Key（分组选择 GPT-Image）。发送后 AI 将立即具备生图和改图能力，之后只需说「帮我生成一张 XXX」即可。

文生图（Text to Image）

发送 JSON 请求，同步返回生成的图片：

curl 'https://jisuai.net/v1/images/generations' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只可爱的猫咪在阳光下打盹",
    "n": 1,
    "size": "1024x1024"
  }'

成功响应：

{
  "created": 1779902762,
  "model": "gpt-image-2",
  "data": [
    {
      "b64_json": "iVBORw0KGgo...(base64 编码的 PNG 图片)",
      "revised_prompt": "AI 优化后的提示词"
    }
  ],
  "usage": {
    "input_tokens": 28,
    "output_tokens": 196,
    "total_tokens": 224
  }
}

以图改图（Image Edit）

上传一张图片并描述修改需求，使用 multipart/form-data 格式：

curl 'https://jisuai.net/v1/images/edits' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -F 'model=gpt-image-2' \
  -F 'prompt=把背景改成日落海滩' \
  -F 'image=@/path/to/your/image.png' \
  -F 'size=1024x1024'

成功响应：

{
  "created": 1779905875,
  "model": "gpt-image-2",
  "data": [
    {
      "b64_json": "iVBORw0KGgo...(base64 编码的修改后图片)",
      "revised_prompt": "AI 优化后的提示词"
    }
  ],
  "usage": {
    "input_tokens": 28,
    "output_tokens": 196,
    "total_tokens": 224
  }
}

请求参数说明

文生图参数

参数类型必填说明
modelstring是固定为 gpt-image-2
promptstring是图片描述文本
nnumber否生成数量，默认 1
sizestring否图片尺寸：1024x1024、1536x1536、2048x2048、1792x1024、2048x1024、1024x1792、1024x2048

以图改图参数

参数类型必填说明
modelstring是固定为 gpt-image-2
promptstring是修改描述文本
imagefile是原始图片文件（PNG/JPG）
sizestring否输出尺寸：1024x1024、1536x1536、2048x2048、1792x1024、2048x1024、1024x1792、1024x2048

响应字段说明

字段说明
data[].b64_jsonBase64 编码的 PNG 图片数据，需解码后保存
data[].revised_promptAI 优化后的实际提示词
usage.total_tokens本次请求消耗的 Token 总量

代码示例

Python

import requests, base64, json

API_KEY = "your-api-key"
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {API_KEY}"
}

# 文生图
resp = requests.post(
    "https://jisuai.net/v1/images/generations",
    headers=headers,
    json={
        "model": "gpt-image-2",
        "prompt": "赛博朋克风格的城市夜景",
        "size": "1792x1024"
    }
)
data = resp.json()
img_bytes = base64.b64decode(data["data"][0]["b64_json"])
with open("output.png", "wb") as f:
    f.write(img_bytes)

# 以图改图
resp = requests.post(
    "https://jisuai.net/v1/images/edits",
    headers={"Authorization": f"Bearer {API_KEY}"},
    files={"image": open("output.png", "rb")},
    data={
        "model": "gpt-image-2",
        "prompt": "添加霓虹灯招牌和飞行汽车",
        "size": "1792x1024"
    }
)
edited = base64.b64decode(resp.json()["data"][0]["b64_json"])
with open("edited.png", "wb") as f:
    f.write(edited)

Node.js

const fs = require("fs");
const FormData = require("form-data");

const API_KEY = "your-api-key";
const BASE = "https://jisuai.net/v1";

// 文生图
async function generate(prompt) {
  const resp = await fetch(BASE + "/images/generations", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${API_KEY}`,
    },
    body: JSON.stringify({
      model: "gpt-image-2",
      prompt,
      size: "1024x1024",
    }),
  });
  const data = await resp.json();
  const buf = Buffer.from(data.data[0].b64_json, "base64");
  fs.writeFileSync("output.png", buf);
}

generate("水墨画风格的山水风景");

常见问题

返回 401 错误？

确认 API Key 创建时选择的分组是 GPT-Image，其他分组的 Key 无法调用图片接口。

图片质量不理想？

尝试用更详细的 prompt 描述画面内容、风格、色调等细节。响应中的 revised_prompt 可以帮你了解 AI 实际理解的内容。

Base64 数据如何使用？

将 b64_json 字段进行 Base64 解码即可得到 PNG 图片的二进制数据，直接写入 .png 文件即可打开。

支持哪些图片格式上传？

以图改图接口支持 PNG 和 JPG 格式的图片上传。
